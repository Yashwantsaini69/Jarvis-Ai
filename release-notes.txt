JARVIS AI 3.39 — Earbud media button

- While Jarvis is connected and the app is in the background (phone locked in
  your pocket), press the earbud button to open Jarvis and start listening.
  Works with play/pause, headset hook, next and previous keys.
- If Jarvis is speaking, the same press stops its speech and plays the chime.
- In the foreground, media buttons are released back to music apps, so music
  controls keep working normally.
- If earbuds are connected but SCO is missing, the app now requests HFP and
  retries routing to the earbud mic for about 1.2 seconds.

HOW TO USE
1. Connect earbuds, start Jarvis once, then lock the phone / put it in pocket.
2. Press the earbud button once. Wait for the chime, then speak.
3. Press again while Jarvis is talking to stop it.
4. If it does not trigger, check DIAGNOSTICS for [MEDIA] and SCO recheck lines.

JARVIS AI 3.36 — Earbud assist

EARBUD LONG-PRESS (POCKET MODE)
- Set Jarvis as your default assistant once: Settings > SET AS DEFAULT ASSISTANT.
- Long-press your earbud (the voice-assistant gesture) to open Jarvis and
  start listening. Works with the phone locked and in your pocket.
- A short chime and a vibration confirm the trigger. If the screen is off,
  Jarvis returns to the background and keeps listening.
- Earbud microphone is used when Bluetooth earbuds are connected (SCO).
- Bluetooth permission is requested once. No call, SMS or contacts access.

HOW TO USE THIS UPDATE
1. Install over the old Jarvis.
2. Open Settings > SET AS DEFAULT ASSISTANT > Allow.
3. Connect your earbuds and lock the phone.
4. Long-press the earbud, wait for the chime, then speak.
5. If the earbud does not send the assistant key, use the app or the media
   controls instead. Behaviour depends on the earbud model (boAt/Mivi/Realme).

JARVIS AI 3.35 — Voice fixes

VOICE RELIABILITY
- Commands run as soon as you stop speaking. The app no longer waits for a
  final transcript marker that Gemini never sends, so replies feel faster.
- Echo fix: Jarvis no longer hears its own reply as a command. Acoustic echo
  cancellation is enabled and echo text is filtered out.
- Voice interrupt still works: you can talk over Jarvis to stop it.

COMMANDS
- Media: "next", "agla", "previous", "pichla" and "stop" work without saying
  song/music.
- Alarm: "alarm band/close/क्लोज करो" now dismisses instead of re-setting.
- Volume in Hindi: "वॉल्यूम मैक्स करो", "ज़्यादा", "कम", "म्यूट".
- "Phone"/"Dialer"/"फोन" opens the real Phone app (no more Mi Remote mix-up).
- Unmute detector is stricter, so the mic is less likely to turn on by itself.

HONESTY
- Jarvis no longer claims it can make calls, send SMS or read/search contacts.
  Those are not available yet. It can still open the Phone/Contacts app.

HOW TO USE THIS UPDATE
1. Install this APK over the old Jarvis (same signing key).
2. Open Jarvis and start the live session.
3. Say "next", "agla", "alarm band karo", "वॉल्यूम मैक्स करो".
4. Say "phone kholo" to open the dialer.
5. If you speak while Jarvis is talking, it should stop and listen.

JARVIS AI 3.33.1 — Voice command fix

VOICE FIX
- Voice commands now reach alarm, timer, flashlight, media and volume even when the live transcription has no final marker.
- A short silence fallback runs the same local command once, without duplicate timers or alarms.
- Spoken numbers are understood: "saat baje", "das minute", "do minute", "ek ghanta".
- Chat/typed commands keep working exactly as before.

WHAT'S NEW IN 3.33
- "Alarm" now sets the phone's Clock app alarm. It never creates a notepad reminder.
- Reminders still work exactly as before: "reminder", "yaad dila", "alert".
- If a sentence has both reminder and alarm, it is treated as a reminder.
- "Alarm band karo" dismisses the next alarm. Add a time to target one.
- "Alarms dikhao" opens the Clock alarms screen.
- "10 minute ka timer" sets a phone Clock timer.
- "Timer band karo" opens the Clock timers screen.
- Voice delete: last reminder, reminder by title, note by title, or all with confirmation.
- Flashlight on, off, and toggle.
- Media play, pause, next, previous, and stop. This controls the same player shown in the notification panel.
- Volume up, down, mute, and set a percentage.
- All device controls run silently.

HOW TO USE THIS UPDATE
1. Install this APK over the old Jarvis (same signing key).
2. Open Jarvis and start the live session.
3. Say "alarm 7 baje lagao" and check the phone Clock app.
4. Say "reminder 7 baje lagao" and check the Jarvis notepad.
5. Say "10 minute ka timer", "flashlight on", "pause", "next song", "volume 50%".
6. Say "last reminder delete karo" or "note delete karo shopping".
7. For "sab reminders delete karo", say "haan" after the confirmation question.

NOTES
- The phone needs a default Clock app for alarms and timers.
- Android does not allow silent bulk delete of Clock alarms. "Alarm band karo" dismisses the next alarm; the Clock app opens for other cases.
- Android does not expose active timer IDs, so "timer band karo" opens the timers screen.
