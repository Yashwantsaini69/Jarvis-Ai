JARVIS AI 3.33.1 — Voice command fix

VOICE FIX
- Voice commands now reach alarm, timer, flashlight, media and volume even when the live transcription has no final marker.
- A short silence fallback runs the same local command once, without duplicate timers or alarms.
- Spoken numbers are understood: "saat baje", "das minute", "do minute", "ek ghanta".
- Chat/typed commands keep working exactly as before.

WHAT'S NEW IN 3.33
- "Alarm" now sets the phone's Clock app alarm. It never creates a notepad reminder.
- Reminders still work exactly as before: "reminder", "yaad dila", "alert".
- If a sentence has both reminder and alarm, it is treated as a reminder.
- "Alarm band karo" dismisses the next alarm. Add a time to target one.
- "Alarms dikhao" opens the Clock alarms screen.
- "10 minute ka timer" sets a phone Clock timer.
- "Timer band karo" opens the Clock timers screen.
- Voice delete: last reminder, reminder by title, note by title, or all with confirmation.
- Flashlight on, off, and toggle.
- Media play, pause, next, previous, and stop. This controls the same player shown in the notification panel.
- Volume up, down, mute, and set a percentage.
- All device controls run silently.

HOW TO USE THIS UPDATE
1. Install this APK over the old Jarvis (same signing key).
2. Open Jarvis and start the live session.
3. Say "alarm 7 baje lagao" and check the phone Clock app.
4. Say "reminder 7 baje lagao" and check the Jarvis notepad.
5. Say "10 minute ka timer", "flashlight on", "pause", "next song", "volume 50%".
6. Say "last reminder delete karo" or "note delete karo shopping".
7. For "sab reminders delete karo", say "haan" after the confirmation question.

NOTES
- The phone needs a default Clock app for alarms and timers.
- Android does not allow silent bulk delete of Clock alarms. "Alarm band karo" dismisses the next alarm; the Clock app opens for other cases.
- Android does not expose active timer IDs, so "timer band karo" opens the timers screen.
